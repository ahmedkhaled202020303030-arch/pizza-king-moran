مولّد مفاتيح إشعارات التطبيق

الأداة تنشئ مفاتيح VAPID محليًا داخل متصفحك باستخدام Web Crypto. المفاتيح لا يتم إرسالها إلى أي خادم.

احتفظ بالمفتاح الخاص سريًا، ولا تضعه في GitHub أو داخل كود التطبيق. سنضيفه فقط في Secrets داخل Supabase.

إذا أنشأت مجموعة جديدة، استخدم المفتاحين الجديدين معًا ولا تخلطهما مع مفاتيح قديمة.
